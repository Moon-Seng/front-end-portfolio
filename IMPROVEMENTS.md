# Portfolio UI/UX Improvements Roadmap

This file lists content/features to add to make the portfolio more recruiter-friendly and conversion-focused.

## 1) Hero that proves impact fast

- 1-line value prop + 2-3 proof points (e.g., **3+ years**, **React/Next.js + DRF**, **end-to-end delivery**)
- Clear CTAs: **Download CV (PDF)**, **Email me**, **View projects**

## 2) Featured projects (recruiter-scannable cards)

For each project card:

- **Problem -> What I built -> Impact** (include numbers where possible)
- Tech chips: React, Next.js, DRF, PostgreSQL, OAuth, RBAC, Docker
- Buttons: **Live demo**, **GitHub**, **Case study**

## 3) Case studies (biggest UX upgrade)

Add a detailed section/page per project with:

- Overview, your role, key features, tech stack
- Challenges & decisions, performance/UX improvements
- Screenshots, what you'd improve next

## 4) "How I work" / Remote-readiness

- Communication + ownership (async updates)
- Tools: Zoom, Slack, Discord, async tools
- Availability / timezone

## 5) Skills section (not just icons)

- Grouped by: Frontend / Backend / DevOps
- Mark items as "Used in production" where true

## 6) Experience timeline with outcomes

- 3-5 bullets per role with measurable wins
- Add stack per role for fast scanning

## 7) Contact UX that converts

- 3 clear options: Email, LinkedIn, GitHub
- "What to include" hint (role, timeline, budget)
- Typical reply time

## 8) Trust signals

- 1-2 testimonials (if available) or "Worked with" logos
- "Now" panel: what you're building/learning
